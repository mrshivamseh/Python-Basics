Q1. Class kya hoti hai? ➡️ Blueprint.
Q2. Object kya hota hai? ➡️ Class ka real instance.
Q3. __init__() kya hai? ➡️ Constructor.
Q4. self kya hai? ➡️ Current object.
Q5. Inheritance? ➡️ Parent class se properties aur methods lena.
Q6. super()? ➡️ Parent constructor/method ko call karna.
Q7. Method Overriding? ➡️ Child class parent ke method ko apne hisaab se change karti hai.
