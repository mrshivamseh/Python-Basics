DAY 12 - EXCEPTION HANDLING

1. try
Jis code me error aa sakta hai.

2. except
Error ko handle karta hai.

3. finally
Hamesha execute hota hai.

4. raise
Khud apna error generate karna.

5. Common Exceptions

ZeroDivisionError
-> Number ko 0 se divide karna.

ValueError
-> Galat type ka input.

FileNotFoundError
-> File exist nahi karti.

Syntax:

try:
    # risky code

except ErrorName:
    # handle error

finally:
    # always execute
