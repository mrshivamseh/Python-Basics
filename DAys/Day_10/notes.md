# Day 10 - Python Modules

## Topics Learned

- Module kya hota hai
- import module
- from module import function
- Multiple functions import karna
- import as alias
- from import as alias
- Custom module banana
- Ek Python file se doosri Python file ke functions use karna

## Important Syntax

import module

from module import function

from module import function1, function2

import module as alias

from module import function as alias

## Examples

import math_operations

math_operations.add(10, 5)

from math_operations import add

add(10, 5)

import math_operations as math

math.add(10, 5)

## Important

- Module ek Python file hoti hai jisme reusable code/functions ho sakte hain.
- import ka use module ko use karne ke liye hota hai.
- Alias kisi module ya function ko temporary/naya naam dene ke liye use hota hai.
- Custom modules bana kar code ko alag-alag files me organize kar sakte hain.
