1. open()
file = open("data.txt", "r")
File open karta hai.
2. close()
file.close()
File ko band karta hai.
3. File Modes
r  → Read
w  → Write (Purana data delete)
a  → Append (Last me data add)
4. read()
file.read()
Puri file ek saath padhta hai.
5. readline()
file.readline()
Ek line padhta hai.
6. readlines()
file.readlines()
Saari lines ko list ke form me return karta hai.
